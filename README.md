# Neswef Café

Premium, mobile-first café website built with HTML, CSS, and vanilla JavaScript.

## Preview locally
Open `index.html` in a modern browser. An internet connection is used for Google Fonts and the remote Unsplash photography.

## Included
- Responsive navigation for mobile and desktop
- Premium cream, espresso, olive, and warm-gold visual system
- Hero, menu filters, story, experience, location/contact, and reservation sections
- Reservation form validation and email-draft preparation
- Scroll reveals with reduced-motion support

## Before going live
- Replace the sample menu, prices, hours, address, and contact email.
- The reservation form currently opens an email draft to `hello@neswef.example`. It does not store requests or confirm bookings; connect a real booking provider/backend and update the recipient.
- Confirm photo licensing and replace images with approved café photography.
- Test on actual mobile devices and check accessibility.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then save. GitHub will show the published URL in the Pages settings once deployment completes.
