# Neswef Café

A premium, responsive café website concept built with semantic HTML, custom CSS, and vanilla JavaScript.

## Preview locally

Open `index.html` in a modern browser. An internet connection is required for Google Fonts and the remote Unsplash photography.

## Experience and features

- Editorial café branding with a warm paper, forest-green, and terracotta palette
- Responsive desktop, tablet, and mobile layouts
- Mobile navigation with keyboard Escape support
- Filterable menu cards with category buttons and accessible pressed states
- Photo-led hero, story, ambience, visit details, and footer
- Reservation request form with native validation and an email-draft handoff
- Scroll reveal animations, back-to-top control, and reduced-motion support
- SEO description, social sharing metadata, and semantic section landmarks

## Before accepting real customers

This is a front-end concept, not a connected booking system. Update all sample details before launch:

- Replace the address, opening hours, email, social handle, menu items, and prices with verified café information.
- Replace `hello@neswef.example` in the form and contact links with the real reservation email.
- The form opens an email draft; it does not store requests or confirm bookings. For real bookings, connect a booking provider or a backend.
- Review the remote image choices and use café-owned or properly licensed photography for the production site.
- Test form submission, mobile layouts, image loading, contrast, and keyboard navigation on real devices.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for GitHub Pages to finish publishing; the Pages settings will show the verified site URL.
